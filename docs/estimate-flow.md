# 실측 → 견적서 전달 흐름

## 전체 흐름

| # | 상태 (status) | 고객 화면 표시 | 누가 | 하는 일 |
|---|---|---|---|---|
| 1 | `received` | 접수됨 | 고객 | 견적 신청 (지금 있음) |
| 2 | `checking` | 확인 중 | 운영자 | 신청 확인, 전화·문자로 실측 일정 잡기 |
| 3 | `visit` **새로** | 실측 예정 · 10/20(월) 오후 | 운영자 | 실측 날짜 입력 → 고객에게 안내 메일 |
| 4 | `needs` | 보완 필요 | 운영자 | (필요할 때만) 사진·정보 추가 요청 |
| 5 | `quoted` | 견적 도착 | 운영자 | 실측 후 항목별 견적서 입력 → "견적서 도착" 메일 + 문자로 링크 |
| 6 | — | — | 고객 | '내 신청'에서 견적서 확인 후 버튼: **진행할게요 / 조정 상담 / 이번엔 보류** |
| 7 | `done` / `hold` **새로** | 진행 확정 / 보류 | 시스템 | 운영자에게 알림 메일. 진행이면 업체 연결 동의 받기 |
| 8 | `canceled` | 취소됨 | 둘 다 | 언제든 |

## 견적서 내용
- 항목별 줄: 작업(잔디·자갈…) · 자재 · 수량/면적 · 자재비 · 배송비 · 시공비
- 합계 (부가세 포함 여부 표시)
- 실측 사진, 실측 메모
- 유효기간 (예: 발행일 +14일)
- 진행 시 일정 예상, 조건·제외 사항

## 만드는 순서
1. **견적서 데이터 + 고객 보기 화면** — DB 표 `quote_estimates` / `quote_estimate_items`, '내 신청'에 견적서 카드. 입력은 Supabase 화면에서 직접.
2. **알림 메일** — 상태가 `visit`·`quoted` 로 바뀌면 고객에게 메일 (Resend, 이미 있음)
3. **고객 응답 버튼** — 진행/조정/보류 → 상태 변경 + 운영자 메일
4. **관리자 화면** — 신청 목록, 실측 일정 입력, 견적서 작성 폼 (Supabase 직접 입력 대체)
5. **업체 연결 동의** — 진행 확정 시 업체 정보 보여주고 제3자 제공 동의
